## Introduction

This repository is a **living, data-driven survey** of research papers about **learning in AI** — covering the full spectrum of machine learning paradigms, from classical supervised learning to modern causal inference.

While many surveys focus on a single learning paradigm, this project aims to provide a comprehensive, structured overview across **22 major learning paradigms** and **8 scope/approach dimensions**, making it easy to navigate the vast landscape of machine learning research.

Papers are stored in [`papers.yaml`](papers.yaml) as structured data. The README is auto-generated by [`scripts/generate_readme.py`](scripts/generate_readme.py) and validated by [`scripts/validate_papers.py`](scripts/validate_papers.py). See [`CONTRIBUTING.md`](CONTRIBUTING.md) for how to add papers.

## Taxonomy

### Categories (Learning Paradigm)

| Category | Description |
|----------|-------------|
| **Supervised** | Supervised learning, classification, regression, labeled data |
| **Unsupervised** | Unsupervised learning, clustering, dimensionality reduction, generative modeling |
| **Reinforcement** | Reinforcement learning, policy optimization, reward learning |
| **Self-Supervised** | Self-supervised learning, contrastive learning, masked prediction, pretext tasks |
| **Meta-Learning** | Learning to learn, few-shot, MAML, hyperparameter optimization, neural architecture search |
| **Continual** | Continual/lifelong learning, catastrophic forgetting avoidance, incremental learning |
| **Transfer** | Transfer learning, domain adaptation, pretraining + finetuning, foundation models |
| **Multi-Agent** | Multi-agent learning, emergent communication, cooperative/competitive learning |
| **Active** | Active learning, query strategies, human-in-the-loop |
| **Online** | Online/streaming learning, bandits, non-stationary environments |
| **Federated** | Federated learning, privacy-preserving distributed learning, differential privacy |
| **Curriculum** | Curriculum learning, self-paced learning, hard example mining |
| **Neurosymbolic** | Neurosymbolic learning, logic + neural integration, differentiable reasoning |
| **Causal** | Causal inference, causal discovery, counterfactual learning, structural causal models |
| **RLHF / Alignment** | RLHF, DPO, KTO, preference optimization, constitutional AI, value learning |
| **Diffusion** | Diffusion models, flow matching, score matching, rectified flow, generative training |
| **World Model** | World models, latent dynamics, environment simulators, predictive models |
| **Multimodal** | Vision-language models, cross-modal learning, audio-visual, embodied perception |
| **Reasoning Models** | Test-time compute, chain-of-thought, system-2 thinking, inference-time scaling |
| **Retrieval-Augmented** | RAG training, retrieval-augmented generation, memory-augmented learning |
| **Imitation** | Imitation learning, behavior cloning, learning from demonstrations, inverse RL |
| **Reward Modeling** | Reward models, preference learning, reward prediction, feedback learning |

### Subcategories (Scope/Approach)

| Subcategory | Description |
|-------------|-------------|
| **Theory** | Theoretical foundations, convergence, generalization bounds, information theory |
| **Algorithm** | New algorithms, methods, architectures |
| **Architecture** | Neural architectures, transformers, CNNs, GNNs, attention mechanisms |
| **Optimization** | Optimizers, regularization, loss functions, learning rate schedules |
| **Scaling** | Scaling laws, compute-optimal training, large-scale training |
| **Efficient** | Efficient learning, compression, quantization, distillation, pruning |
| **Robust** | Robustness, adversarial, out-of-distribution, fairness, safety |
| **Application** | Applied learning in specific domains (NLP, CV, robotics, science, healthcare) |
